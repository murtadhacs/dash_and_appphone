# مدرسة الرحمن — تطبيق ولي الأمر (Flutter)

تطبيق ولي الأمر مربوط بـ Future Kids API (قسم Parent App، بما فيه إضافات الإصدار 1.19.0).

## التشغيل

```bash
flutter pub get
flutter run                                   # على staging افتراضياً
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8080   # خادم محلي من محاكي أندرويد
```

## البنية

```
lib/
├── main.dart              التطبيق + العودة للدخول عند 401/403
├── app_scope.dart         الخدمات المشتركة (ParentApi + navigatorKey)

├── api/                   ApiClient، ParentApi (/api/mobile/*)، SessionStore (تخزين آمن)
├── data/parent_data.dart  مالك البيانات بعد الدخول (ChangeNotifier)
├── core/                  توقيت بغداد، أيام الأسبوع الدراسي، بناء تقويم الشهر
├── models/                ParentProfile، Student، MonthlyRecord، DaySchedule، AppNotification، SchoolBanner
├── screens/               البداية، الدخول، التحميل، الرئيسية، الحضور، الجدول، الإشعارات، الإعدادات
├── widgets/               ودجتات مشتركة (منها BannerCarousel)
└── theme/                 الألوان والخطوط
```

## من التصميم إلى الـ API

| الشاشة | المصدر |
|---|---|
| الدخول | `POST /api/mobile/login` برقم الهاتف (أي صيغة عراقية) والرمز السري. التوكن وبيانات ولي الأمر في التخزين الآمن، والرمز لا يُحفظ |
| الرئيسية | `students` + `attendance/today` + `schedule` + `banners` |
| الحضور | `attendance/monthly?month=` مع التنقل بين الأشهر |
| الجدول | `schedule` (أسماء الأيام تُوحَّد: بهمزة أو بدونها أو بالإنجليزية) |
| الإشعارات | `notifications` بالصفحات + `read?id=` + `read-all` |
| الإعدادات | بيانات ولي الأمر + واتساب الإدارة + مفتاح إشعارات الحساب + حذف الحساب مع PIN |

## حذف الحساب وإشعارات الهاتف (API 1.19.0)

- حذف الحساب: تحذير بفصل جميع الأبناء، ثم `POST /api/mobile/account/delete` مع PIN كما كتبه المستخدم. النجاح يمسح الجلسة والتخزين الآمن والبيانات المؤقتة ويعود للدخول. لا يُرسل حذف device-token بعد حذف الحساب.
- أخطاء 400 و429 تبقي الجلسة وتعرض الرسالة؛ 429 يعرض مدة الانتظار من `Retry-After`. فقط 401 و403 يعيدان تسجيل الدخول.
- مفتاح الإشعارات يقرأ `GET /api/mobile/notification-settings` ويحفظ `push_enabled` عبر PUT، مع تحذير قبل الإيقاف. الإذن في نظام الهاتف يظهر في سطر مستقل ويتحدث عند العودة من الإعدادات.
- عند التشغيل يُحفظ الإعداد أولاً ثم يُعاد تسجيل الجهاز إذا توفر رمز فعلي، ويُقرأ `registered` من الرد؛ false حالة ناجحة طبيعية.
- Firebase مفعّل على Android بالمعرّف `me.yisawi.futurekids.alrahman` وملف `android/app/google-services.json`. يُطلب إذن الإشعارات بعد الدخول/استعادة الجلسة، ويُرسل FCM token بعد الدخول وعند بدء التطبيق وتجديد الرمز، ويُحذف تسجيل الجهاز عند الخروج. الإشعارات في المقدمة تُعرض محلياً في قناة `attendance_alerts`. إعداد iOS يحتاج ملف Firebase خاصاً به لاحقاً.

- "غائب" قبل الساعة 12:00 بتوقيت بغداد تُعرض "لم يصل بعد" (الخادم يعدّ من لم يصل غائباً).
- السحب للأسفل يحدّث حضور اليوم والإشعارات والبنرات، وكذلك العودة إلى التطبيق.
- الإصدار 1.0.1: البنرات للعرض فقط دون فتح روابط، وتظهر الصورة الجديدة بعد استبدالها وتحديث التطبيق.

## لم يُنفَّذ بعد

- **إشعارات الدفع على iOS:** تحتاج إعداد Firebase خاصاً بـiOS وملف `GoogleService-Info.plist`؛ ربط Android مكتمل.
- أوقات الحصص والفسحة: الخادم لا يرسلها، فأُزيلت من التصميم.
